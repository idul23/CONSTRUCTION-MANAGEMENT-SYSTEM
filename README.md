# Construction Project and Labor Management System

A simple web-based system for managing construction projects, workers, tasks, materials, attendance, material usage, expenses, and reports.

## Features

- Project Management
- Worker Management
- Task Management
- Material Inventory
- Material Usage Tracking
- Worker Attendance
- Expense Management
- Reports
- User Management
- Login System

## Technologies

- PHP
- HTML
- CSS
- SQLite
- Git
- GitHub

## System Users

### Administrator
Manages users, workers, projects, materials, and system records.

### Project Manager
Creates and monitors projects, assigns workers to tasks, tracks progress, and monitors expenses.

### Site Staff
Records worker attendance, work hours, material usage, and task progress.

## How to Run

1. Install PHP.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

php -S localhost:8000

5. Open:

http://localhost:8000
